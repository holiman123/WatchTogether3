# WatchTogether3

WatchTogether3 solves one problem - watching videos with your friends online.

When we want to do it usualy we decide to pick one person with the best internet and make him stream the video through Discord or SkYpE.
But picture quality, sound quality, delays are coming in our way and ruins all impression.

Here I'm trying to create website which will make watching as easy as possible by using this features:
- Shared controls:  
  Video is controllable by multiple users. Anybody can pause/proceed/seek video and everyone else would be synchronised.
- Rooms:  
  Users create personal rooms where videos are stored. They can control room privacy and upload videos to the room.
- Friends sustem:  
  Users can add each other as friends which adds easy connection and more privacy control to rooms.

### It's possible to upload videos from your machine or from youtube via link. ###
